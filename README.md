# Quick-Open-URLs for Chrome extensions
In just two steps, you can quickly open multiple URLs or URLs in text format


Quickly open all links in selected text using keyboard shortcuts, supporting lazy loading, tab groups, containers, etc.

## Latest Update

**v1.1** - Basically Completed

## Features

- Quickly open selected URLs using keyboard shortcuts (Ctrl+Shift+E / Command+Shift+E)

- Supports lazy loading mode

- Supports tab group management

- Supports container functionality

- Configurable options page

## Installation

1. Download the project code

2. Open the extension management page in Chrome/Edge browsers

3. Enable developer mode

4. Click "Load unpacked extension"

5. Select the project folder

## How to Use

1. Select text containing URLs on a webpage

2. Press the keyboard shortcut Ctrl+Shift+E (Mac: Command+Shift+E)

3. All detected URLs will open in a new tab.


# Quick-Open-URLs

通过快捷键快速打开选中文本中的所有链接，支持懒加载、标签组、容器等。

## 最新更新

**v1.1** - 基本完成

## 功能特性

- 使用快捷键 (Ctrl+Shift+E / Command+Shift+E) 快速打开选中的 URL
- 支持懒加载模式
- 支持标签组管理
- 支持容器功能
- 可配置的选项页面

## 安装

1. 下载项目代码
2. 打开 Chrome/Edge 浏览器的扩展管理页面
3. 开启开发者模式
4. 点击"加载已解压的扩展程序"
5. 选择项目文件夹

## 使用方法

1. 在网页上选中包含 URL 的文本
2. 按下快捷键 Ctrl+Shift+E (Mac: Command+Shift+E)
3. 所有检测到的 URL 将在新标签页中打开
